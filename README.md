# Zegar

A clock-reading trainer for children, in Polish. Drag the hands of an analog clock and see the time
in Polish words: *wpół do czwartej*, *za kwadrans szósta*.

**Try it:** https://kandelucky.github.io/zegar/

- **Zegar**: a free clock you can drag, shown in words or digits, and read aloud, with a **Trening** tab for practice
- **Lekcje**: 6 short lessons, from units of time to elapsed time
- **Ćwiczenia**: 10 levels, from full hours to elapsed time and a final „Mistrz" level, plus a bonus level
  where more than an hour passes

To run it, open `index.html` in a browser. There is no build step, and it works offline.
